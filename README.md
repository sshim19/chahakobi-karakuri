# 茶運びからくり

左の指でからくりの足を歩かせ、右の指で盆を水平に保ち、今日の席へお茶を届けるゲームです。同じ日は、だれが遊んでも同じ廊下です。携帯は横向きで、両手で遊びます。

## 遊び方

1. 画面を横向きにして、「運ぶ」を押します。制限時間は75秒です。
2. 左の指で歩行のレバーを上下し、右の指で盆の傾きを整えます。マウスなら、片方ずつ動かすことができます。
3. 速さが安定しているときだけ、足取りが滑らかです。席の前で止まって、お茶を差し出します。歩く速さが変わったり、畳の段差に乗ったりすると、盆は傾きます。
4. 22秒を過ぎれば「仕舞う」で早めに確定しても構いません。今日の席へすべて届けたら、22秒前でも確定します。時間が来ると、そこまでの運びで終わります。茶碗が倒れたときは、その瞬間に終わります。

最高記録と、その日の最高記録は、この端末に保存されます。0点は記録しません。

終了画面の X と LINE のボタンから、いまの得点をそれぞれの投稿画面で共有できます。

## 開き方

ビルドは不要です。フォルダをウェブサーバーで公開するか、手元では次のように開きます。

```bash
python3 -m http.server
```

ブラウザで `http://localhost:8000/` を開いてください。`file://` では動きません。
